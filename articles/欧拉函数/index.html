欧拉函数

Locklink
2025-12-18

定义

欧拉函数即 φ(n)\varphi(n)φ(n)，表示的是小于等于 nnn 和 nnn 互质的数的个数。
φ(1)=1\varphi(1) = 1φ(1)=1。当 nnn 是质数的时候，有 φ(n)=n−1\varphi(n) = n - 1φ(n)=n−1。

性质

欧拉函数是积性函数。

n=∑d∣nφ(d)n = \sum_{d \mid n}{\varphi(d)}n=∑d∣n​φ(d) 。

$ \varphi(n) = n \prod (1 - \frac{1}{p_i}) $。

洛谷 P2398 GCD SUM

∑i=1n∑j=1ngcd⁡(i,j)\sum_{i=1}^{n} \sum_{j=1}^{n} \gcd(i,j) i=1∑n​j=1∑n​gcd(i,j)

=∑i=1n∑j=1n∑d∣gcd⁡(i,j)ϕ(d)= \sum_{i=1}^{n} \sum_{j=1}^{n} \sum_{d \mid \gcd(i,j)} \phi(d) =i=1∑n​j=1∑n​d∣gcd(i,j)∑​ϕ(d)

=∑i=1n∑j=1n∑d∣i,d∣jϕ(d)= \sum_{i=1}^{n} \sum_{j=1}^{n} \sum_{d \mid i, d \mid j} \phi(d) =i=1∑n​j=1∑n​d∣i,d∣j∑​ϕ(d)

=∑i=1n∑j=1n∑d=1nϕ(d)[d∣i][d∣j]= \sum_{i=1}^{n} \sum_{j=1}^{n} \sum_{d=1}^{n} \phi(d) [d \mid i] [d \mid j] =i=1∑n​j=1∑n​d=1∑n​ϕ(d)[d∣i][d∣j]

=∑d=1nϕ(d)∑i=1n∑j=1n[d∣i][d∣j]= \sum_{d=1}^{n} \phi(d) \sum_{i=1}^{n} \sum_{j=1}^{n} [d \mid i] [d \mid j] =d=1∑n​ϕ(d)i=1∑n​j=1∑n​[d∣i][d∣j]

=∑d=1nϕ(d)⌊nd⌋2= \sum_{d=1}^{n} \phi(d) \left\lfloor \frac{n}{d} \right\rfloor^2 =d=1∑n​ϕ(d)⌊dn​⌋2

这是线性筛法求欧拉函数，在用线性筛法找出每个数的最小质因数的同时，利用欧拉函数的积性性质，递推出每个数的欧拉函数值。
时间复杂度 O(n)\text{O}(n)O(n) 。
