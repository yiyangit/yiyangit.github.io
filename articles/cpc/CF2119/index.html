Statement

合法序列 aaa 满足 0≤ai≤i0 \le a_i \le i0≤ai​≤i。
f(a)f(a)f(a) 的定义为：初始有 nnn 个标记，依次从 [ai,i][a_i,i][ai​,i] 上移除一个标记（ ai=0a_i=0ai​=0 则不做操作），f(a)f(a)f(a) 即为移除标记排列数。

给定 n≤5000n \leq 5000n≤5000，对于所有长度为 nnn 的合法序列 aaa，求 ∑f(a)\sum{f(a)}∑f(a) 。答案对 mmm 取模。

Solution

正难则反，考虑对每一种标记移除排列方案，从后往前考虑每一个被移除的标记 iii ，设已经被移除的标记数为 jjj，其可能的被移除的方式有 i×(n−i+1−j)i \times (n-i+1-j)i×(n−i+1−j) 种。对于整个排列方案，运用乘法原理即可。

令 dp[i][j] 为到位置 iii 的标记，已经移除了 jjj 个标记的答案数，从后往前 dp 即可。

E

Statement

给定一个长度为 n−1n-1n−1 的序列 aaa 和一个长度为 nnn 的序列 bbb。要求增加 bib_ibi​ 的值（可以不变）使得 bi&bi+1=aib_i \& b_{i+1} = a_ibi​&bi+1​=ai​ 并使得 bib_ibi​ 的总增加量最小，求这个最小值。 n≤105,ai,bi<229n \le 10^5 , a_i,b_i < 2^{29}n≤105,ai​,bi​<229 。

solution

首先 bib_ibi​ 一定是 ci=ai−1∣aic_i = a_{i-1} | a_{i}ci​=ai−1​∣ai​ 的超集，只需要在 cic_ici​ 的基础上加位保证大于等于 bib_ibi​ 且满足约束条件即可。

对于每一个 cic_ici​ ，从高到低位扫描，若是 111 就跳过（不能做改动），若是 000 就考虑变 111 ，如果变之后大于等于 bib_ibi​ 就将这个数加入候选列表里然后继续往下一位扫描，如果仍然小于就将这一位 111 固定下来（这一位若不为 111，如何改动后面的低位也无法让这个数大于 bib_ibi​ 了）然后继续往后扫描，不难看出这一流程之后每个 iii 可取的数的数量不会超过 323232 ，然后dp即可。
