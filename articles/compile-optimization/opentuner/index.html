Opentuner 自动编译优化框架

Locklink
2026-03-08

OpenTuner 是一个自动调参框架，它自动搜索参数空间，找到使程序性能最优的参数配置。

安装使用

使用 Opentuner 的主要流程为：
继承 MeasurementInterface → 实现 manipulator() + run() → 调用 main()

以用 g++ 编译一个简单的 C++ 程序为例。

manipulator

manipulator() 定义了我们要调优的参数空间。

ConfigurationManipulator 用于描述参数空间。本例只有一个整数参数 BLOCK_SIZE，范围 1 ~ 10。
OpenTuner 支持多种参数类型，例如：IntegerParameter EnumParameter BooleanParameter FloatParameter。

run

命令行参数

opentuner.default_argparser() 会提取程序的命令行参数，可用的命令行参数包括：

  • --technique：测试所用的算法。
  • --test-limit：最多测试的次数。
  • --stop-after：测试终止的时间。
  • --parallelism ：并行的测试数目。
  • --database ：数据库文件。
