关于 nginx 配置

nginx 启动时，会加载 /etc/nginx/nginx.conf 配置文件。
而 /etc/nginx/nginx.conf 会引入：

  • /etc/nginx/conf.d 中以 .conf 结尾的配置文件
  • /etc/nginx/sites-enabled 中任何名称的配置文件
    sites-available 中拥有名为 default 的配置文件以供参考。
