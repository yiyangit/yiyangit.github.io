D

Statement

有 n≤2×105n \leq 2 \times 10^5n≤2×105 个精灵，他们有生命值 hih_ihi​ 和攻击力 aia_iai​ ，初始有 hi=aih_i=a_ihi​=ai​ 且不同精灵的攻击力不相同。

重复以下过程：

  • 任选两个活着（ hi>0h_i>0hi​>0 ）的精灵 x,yx,yx,y ，让没有发起过攻击的精灵 xxx 发起一次攻击，使双方的生命值扣除对方的攻击力。如果无法执行操作，过程结束。

给定整数 mmm ，构造一组攻击序列使得结束时恰好有 mmm 个精灵存活。

Solution

首先当 m>⌊n2⌋m > \lfloor\frac{n}{2}\rfloorm>⌊2n​⌋ 时一定无解（一定还有可以互相杀的），考虑按照攻击力排序，既然要让 mmm 个最终存活，不妨钦定攻击力最高的 mmm 个最终存活，让他们分别攻击另外 mmm 个精灵（目的是消耗掉他们的攻击机会），再让剩下的 k=n−2×mk = n - 2 \times mk=n−2×m 个精灵按照攻击力排序呈“链状”主动攻击送死即可。

如果 m=0m=0m=0 即所有精灵全部死亡怎么办？最后一次攻击必须是两个精灵同归于尽，那么其中较强的一个一定已经被消耗，依然钦定攻击力最高的两个活下来，按照攻击力从小到大排序找到若干个精灵用于削弱最强的精灵，剩下的依旧“链状”主动攻击次弱的即可。

Statement

交互题。数组 aaa 由如下方式生成：

  • 初始 a=b=[2k]a=b=[2^k]a=b=[2k] 。
  • 以任意顺序执行至少零次以下两种操作：
  • 选择 aaa 与 bbb 中的一个，若其最大的一个元素是偶数 xxx ，用两个 x2\frac{x}{2}2x​ 替换它。
  • a,b:=a+ba,b := a+ba,b:=a+b （ +++ 代表拼接操作）。
  • 最后 bbb 将会被丢弃。

你可以进行至多 300300300 次查询：询问 l,rl,rl,r ，返回 aaa 在 [l,r][l,r][l,r] 的区间和 。你要找到 aaa 中最大元素的值。 n≤105n \le 10^5n≤105 。

Solution

由于每次总是分裂大的那个数，对于任意一个区间，按照区间和将其均等分割为两个区间，最大值一定在较短的那个区间里。二分查询，可以在 300300300 次查询以内找到答案。
